PC control

Phone companion

On your phone: Bluey app → Pair → pick this PC (same Wi-Fi) or type the IP, then enter the 6-digit code. Keep it private - anyone with it can control this PC. On the Windows Firewall prompt, allow Private networks only - and if your Wi-Fi (e.g. a phone hotspot) is marked Public, set it to Private first (Windows Settings → Network & Internet → Wi-Fi), or the phone will time out.
